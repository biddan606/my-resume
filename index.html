보유한 기술 스택입니다

Spring Boot

  • Spring Framework의 내부 동작 방식(Bean 생성 및 등록 과정, AOP Proxy 적용 방식 등)을 이해하고 있어 문제 발생 시 디버깅이 용이합니다.
  • JPA와 Hibernate의 동작 원리(영속성 컨텍스트, 지연 로딩, 캐싱 등)를 이해하여 N+1 문제나 성능 이슈를 효과적으로 해결할 수 있습니다.
  • Spring의 트랜잭션 관리 메커니즘을 이해하고 있어, 적절한 격리 수준과 전파 설정을 통해 데이터 일관성을 보장할 수 있습니다.

Docker

  • 다단계 빌드를 통해 빌드 스테이지와 실행 스테이지를 분리하여 최종 이미지 크기를 최적화할 수 있습니다.
  • 도커 레이어 캐시를 효율적으로 활용하여 빌드 시간을 단축하고, 이미지 재사용성을 향상시킬 수 있습니다.
  • 볼륨 마운트와 네트워크 설정을 통해 개발 환경과 운영 환경의 일관성을 유지할 수 있습니다.

AWS

  • 다양한 배포 방식(EC2, Elastic Beanstalk, Lightsail, ECS)의 경험이 있어, 프로젝트 규모와 요구사항에 따라 적절한 배포 전략을 선택할 수 있습니다.
  • EC2와 RDS의 보안 그룹 설정, IAM 역할 관리를 통해 안전한 인프라 구성이 가능합니다.
  • Auto Scaling의 스케일 업/다운 메커니즘을 이해하고 있어, 인스턴스 준비 시간과 쓰로틀링을 고려한 적절한 스케일링 정책을 설정할 수 있습니다.

프로젝트 개요

코딩테스트 스터디 플랫폼으로 마음이 맞는 스터디원들을 모집하고 Solution 템플릿을 제공합니다. 이를 통해 코딩테스트 리뷰에 있어 체계적인 설명이 가능합니다.
LLM의 등장으로 해결책 자체는 쉽게 얻을 수 있게 되었습니다. 이 점을 고려하여 저희 플랫폼은 단순한 해결책보다 문제 해결 접근 방식과 코드 작성 의도에 초점을 맞춘 스터디 경험을 제공합니다.

주요 구현 사항

  • 도메인 분석에 따른 API 문서 개발
    • 도메인 분석을 통해 놓치고 있는 개념 발견 및 프론트 UI 중심이 아닌 도메인 중심 설계
    • OpenAPI 문법을 활용한 체계적인 API 명세 작성
    • Docker-compose를 통해 API 문서를 UI(Redoc)로 제공하여 접근성 향상
  • 일관성 있는 API 요청/응답 구현
    • JSON:API 스펙을 통한 정상 요청/응답 처리로 관계형 리소스의 효율적 표현
    • ProblemDetail 스펙을 활용한 명확한 예외 처리 및 에러 응답 구현
    • 프론트엔드와의 병렬 개발을 통한 개발 효율성 증대
  • JSON:API를 통해 프론트엔드는 한 번의 네트워크 요청으로 관계된 데이터를 효율적으로 조회 가능
  • ProblemDetail을 통해 구체적인 예외 정보와 키워드를 제공하여 프론트엔드의 에러 처리 용이성 확보
  • API 우선 설계를 통해 전체적인 개발 과정을 먼저 파악하고 API 수정을 최소화하는 개발 방식 적용
