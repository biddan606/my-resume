기본에 충실한 개발: 견고한 기본기를 바탕으로 실제 문제를 해결하는 데 집중합니다. 필요한 경우 새로운 기술을 신중하게 평가하고 적용합니다.

보유한 기술 스택입니다

Spring Boot

  • Spring Framework의 내부 동작 방식(Bean 생성 및 등록 과정, AOP Proxy 적용 방식 등)을 이해하고 있어 문제 발생 시 디버깅이 용이합니다.
  • JPA와 Hibernate의 동작 원리(영속성 컨텍스트, 지연 로딩, 캐싱 등)를 이해하여 N+1 문제나 성능 이슈를 효과적으로 해결할 수 있습니다.
  • Spring의 트랜잭션 관리 메커니즘을 이해하고 있어, 적절한 격리 수준과 전파 설정을 통해 데이터 일관성을 보장할 수 있습니다.

Docker

  • 다단계 빌드를 통해 빌드 스테이지와 실행 스테이지를 분리하여 최종 이미지 크기를 최적화할 수 있습니다.
  • 도커 레이어 캐시를 효율적으로 활용하여 빌드 시간을 단축하고, 이미지 재사용성을 향상시킬 수 있습니다.
  • 볼륨 마운트와 네트워크 설정을 통해 개발 환경과 운영 환경의 일관성을 유지할 수 있습니다.

AWS

  • 다양한 배포 방식(EC2, Elastic Beanstalk, Lightsail, ECS)의 경험이 있어, 프로젝트 규모와 요구사항에 따라 적절한 배포 전략을 선택할 수 있습니다.
  • EC2와 RDS의 보안 그룹 설정, IAM 역할 관리를 통해 안전한 인프라 구성이 가능합니다.
  • Auto Scaling의 스케일 업/다운 메커니즘을 이해하고 있어, 인스턴스 준비 시간과 쓰로틀링을 고려한 적절한 스케일링 정책을 설정할 수 있습니다.

프로젝트 개요

GitHub에서 코딩테스트 풀이를 자동으로 수집하여 스터디원들과 공유할 수 있는 플랫폼입니다. 코드 리뷰와 토론을 통해 효과적인 알고리즘 학습을 지원합니다.

주요 구현 사항

  • GitHub API 성능 최적화 및 장애 복구 시스템 구축
    • 청크 단위 트랜잭션 처리를 통한 대용량 데이터 처리 성능 향상
    • 작업 재시작 시 실패 지점부터 자동 재개되는 장애 복구 매커니즘 구현
    • Step 단위 격리로 동시 작업 처리 시 발생하는 리소스 경합 문제 해결
  • 게시글 및 댓글 시스템 구현
    • 사용자 권한 기반 데이터 접근 제어로 안전한 CRUD 운영
    • 회원 및 게스트 댓글 작성 기능으로 참여 접근성 향상
    • 오늘의 코딩테스트 문제 등록 및 관리 기능 구현
  • 세션 기반 사용자 인증 시스템 직접 구현을 통한 안전한 사용자 관리
  • JPA 엔티티 설계 및 쿼리 최적화를 통한 데이터베이스 성능 개선
  • Docker를 활용한 컨테이너화와 AWS ECS를 통한 안정적인 배포 환경 구축
